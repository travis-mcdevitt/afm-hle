# Gemini 3.7 Flash trial — 2026-09-16

The configured `nous-gemini-3.7-flash` route successfully graded the same 50 saved
AFM responses as the o3-mini reference. No additional Apple requests were made.
All reference and GLM grades remain intact in their original private databases.

## Compatibility finding

Four synthetic calls tested formatting. The minimal one-field JSON schema worked;
the full reference schema returned an empty object, even with explicit JSON-format
instructions. Removing only the API boolean `enum: [true]` constraint from the
`strict` field produced a valid grade. This isolates a compatibility issue in the
tested route/schema combination; it does not locate it definitively in the model,
provider, or proxy. The `portable-boolean` profile records that API variation.
Local validation still requires the exact reference fields, `strict is True`,
valid confidence, and yes/no correctness. The judge prompt and 4,096-token ceiling
were unchanged. Comparisons explicitly disclose the schema variation.

## Saved-response comparison

| Generated by | Reference correct | Gemini correct | Correctness agreement |
| --- | ---: | ---: | ---: |
| AFM Cloud | 0/25 | 0/25 | 25/25 |
| AFM Cloud Pro | 2/25 | 3/25 | 24/25 |

Overall correctness agreement: **49/50 (98%)**. Confidence extraction agreed on
all 50 responses. For Cloud Pro, positive agreement is 0.8; for Cloud there are
no positive labels, so positive agreement is undefined. High overall agreement
on this small, mostly incorrect sample is not proof of judge equivalence.

The one disagreement concerns how a response's explanation answers the underlying
yes/no question. Gemini interpreted it as matching the reference answer; o3-mini
instead extracted details from the explanation and judged a mismatch. The raw
response and both rationales are saved privately in `.private/gemini-disagreements.json`
for adjudication. Neither judgment was overwritten, and no adjudicated score is
claimed here. This is a small partial HLE run, not a full benchmark result.

## Reliability and cost

All 50 HLE grades validated on the first attempt after applying the schema profile.
Returned model IDs were `nous-gemini-3.7-flash`; this is route-level provenance, not
an immutable underlying model attestation. Observed median latency was 3.06 seconds
and nearest-rank p95 4.11 seconds. These were sequential calls, not a load test.

HLE grading used 51,150 input and 8,609 output tokens. Usage-based and proxy-reported
cost both total **$0.07064625**, at the route's $0.75/M input and $3.75/M output
rates. The four synthetic diagnostics add **$0.002667** in estimated cost, for
**$0.07331325** total known trial cost. The reference's 50 successful grades cost
$0.130097, excluding its one failed request of unknown cost. Tokenization and
reasoning usage differ between judges; cost comparisons are specific to this run.

[Machine-readable comparison](../reports/gemini-comparison.json) includes prompt,
schema and response hashes, separate judge scores, usage, costs, and latency.
Twenty-six offline tests pass. No background inference process remains active.

Gemini is a working candidate for continued grading using this schema profile.
The original reference baseline remains the default; this trial did not switch
`.env` or overwrite the project's reference-grader configuration.
